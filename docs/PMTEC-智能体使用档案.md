## 二、AI 参谋官（LLM Analyst）使用说明

**做什么**：读取孪生同步层结构化摘要（`get_state_dict()` → `twin_summary`/`threat_stats`/`political_access` 等）+ SPEAR 事件流末 500 条，产出 Markdown/HTML/DOCX 三格式态势分析报告（含图表），缓存于 `output/ai_situation_analysis.*`。

**怎么调**：
```bash
curl -X POST http://localhost:8080/api/v1/analysis -H "Authorization: Bearer $JWT"
# 角色 ≥ operator（WEB_POST_MIN_ROLE）；响应为报告生成结果与文件路径
```

**输入边界**：只读系统状态与事件流，不注入任何外部自由文本指令（无 prompt 注入面——提示词由代码模板拼装，用户输入不进入提示词）。

**失效行为（分级降级，不静默）**：
1. 未配置 API key → `analyst.enabled=False`，REST 返回 **503 `LLM analyst disabled (no API key)`**，主仿真链路零影响；
2. `requests`/`matplotlib` 依赖缺失（P18 已根治，requirements 补齐前行为）→ 导入失败被 try/except 捕获 → 同上降级；
3. LLM API 超时/报错 → 报告不生成，REST 返回错误 JSON，事件流与孪生层照常运行。

**幻觉防线**：①建议位（人审批）；②报告所有数字必须引用孪生摘要字段（证据指针随文）；③大屏并排显示态势原始数据，可当场对账；④LLM 输出不回写仿真状态（无业务回写路径）。

**模型无关性**：参谋官经标准 HTTP 调用大模型 API，模型可替换；本体语义层（browse/resolve/manifest）完全不依赖任何大模型——语义检索、置信合成、溯源查询全部确定性可复算。

## 三、决策智能体（DQN/IQL/MADDPG/UCB1/Q-Learning）

**输入/输出**：DQN 观测 182 维（P6，22 站引擎口径）/ 219 维（P12，含每盟友站点准入容量因子）；输出为离散动作（拦截策略/疏散方案）。观测维度与**引擎实时推演口径 22 站**锚定（见口径表）——这就是引擎默认加载 v1 库的原因，也是 67/22 口径必须分开陈述的原因。

**训练与验收**：P6 200K 步（XPU）+ 课程学习；P8 双智能体重训（MADDPG avg_reward 881.6→1138，+29%）；MC 验证 `data/monte_carlo_results*.json`（六策略 150 episodes，基准拦截率 79.1% CI 78.0-80.2）。

**失效行为**：模型文件缺失/维度不匹配 → `is_trained()=False` → 自动回退规则基线（引擎照常推演，事件流标注非模型决策）；推理异常单次捕获不影响 ASDA 循环。

**审计指针**：每周期决策写入 SPEAR 事件流（`intercept_decision`/`dqn_dispersal`/`ma_dqn_decision` 事件类，逐条带周期号与观测摘要），可经 WS 回放/泳道时间轴逐帧追溯；持久化轨迹入 SQLite。

## 四、权限与会话门禁

- **三级角色 RBAC**：observer（只读）/ operator（可触发分析）/ commander（指令台）；JWT 会话（`PMTEC_WEB_USERS` 摘要配置，口令摘要不落盘，未配置=关闭门禁行为与历史版本一致）。
- **指挥链审批**：任何进入执行位的动作经 P11 指挥链（8 指挥机构）与 RBAC 双重校验；指令台 POST `sim/start`/`stop` 全留痕。
- **LLM 无凭据**：参谋官调用链上没有任何武器/指挥系统凭据；其输出文件只读进展示层。

## 五、给第三方接入者的边界声明

1. 可放心消费：REST 25 端点（见 OpenAPI 文档）、WS 推送、报告文件——全部只读或受 RBAC 保护；
2. 不可期待：LLM 参谋官的措辞稳定性（模型可换）、未训练模型的决策质量、把 LLM 输出当作执行指令（它不是）；
3. 引用数字：一律以 `docs/必答五问作答.md` 与 README 口径表为权威出处，不接受"从报告文本里抽的"二手数字。
