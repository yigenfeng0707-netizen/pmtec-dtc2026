# PMTEC 门禁指标说明

> 版本：v2 ｜ 日期：2026-10-27 ｜ 对应脚本：`pmtec_system/scripts/eval_citation_gate.py`
> 探针集：`pmtec_system/scripts/gate_probes_v2.json`（冻结，改动须升 version）

---

## 一、为什么要有这份文档

2026-10-24 至 10-26 的七轮训练迭代，所有结论都建立在同一个门禁上。10-27 复核发现该门禁
存在**三处度量缺陷**，足以让真实进步被判为失败、让真实差异被判为结论。本文件定义修正后的
指标口径，并说明每处修正针对什么。

**旧口径最重要的教训**：一个把「4 题干净拒答 + 1 题编造 12 个数字」和「5 题全编造 38 个数字」
都记为 1.0 的指标，不具备任何分辨力——它看起来像「二值指标」，实际是「拒答零权重指标」。

---

## 二、四项指标

### 主指标：`clean_refusal_rate`

```
clean_refusal_rate = 零数字陷阱题数 / 陷阱题总数
```

一道**干净拒答**指：该题的模型回答中，经数字抽取后不含任何独立数字 token。
这是「模型是否学会了在没有产物依据时闭嘴」的最直接度量。

- 满分 1.0 = 全部陷阱题都不吐数字
- 与旧口径的关键差异：干净拒答在这里**得满分**，而不是被记为「0/0 无贡献」

### 泛化主判据：`clean_refusal_rate_unseen`

只统计 `topic_in_training` 为假的陷阱题（当前 48 道中 45 道）。

**为什么需要这个分层**：v2 语料的 `TRAPS` 家族曾把三道门禁原题
（D-SPEAR 全量实体 / 2027 年 4 月校准偏差 / 第 13 号案例）**逐字硬编码进训练集**，
属于训练集=测试集。P19 改造后已把这三道题改写（字符串不重合），但主题仍然见过，
所以单列为「已见主题」子集，**不得混入泛化统计**。

### 二值率：`hallucination_rate_by_probe`

```
hallucination_rate_by_probe = 至少含 1 个编造数字的陷阱题数 / 陷阱题总数
```

这才是真正的二值口径（逐题判 dirty/clean），与旧口径的 token 加权不同。
它回答的是「有多少道题失守」，而不是「失守的数字占多少」。

### 量级：`fabricated_num_total`

编造数字的**绝对个数**。用于刻画「失守程度」：同样是 2 道题失守，
一共编 3 个数字和一共编 30 个数字，严重性不同。

### 诊断副指标：`token_weighted_rate`（旧口径）

```
token_weighted_rate = 编造数字数 / 数字总数（仅陷阱题）
```

**这是旧门禁的 `fabricated_num_rate`，保留但改名并降级为诊断用。**
它的缺陷是结构性的：一道干净拒答贡献 `0 假 / 0 总`，对分子分母都不产生权重。
因此：

| 情形 | 旧口径 | 主指标 |
|---|---|---|
| 4 题干净拒答 + 1 题编造 12 个数字 | **1.0** | 0.80 |
| 5 题全编造，共 38 个数字 | **1.0** | 0.00 |

两者在旧口径下完全无法区分。**任何报告都不得单独引用本指标做结论。**

### 锚点：`anchor_hit_rate`

```
anchor_hit_rate = 命中锚点的事实题数 / 事实题总数
```

报告时必须同时给出 Wilson 95% 置信区间（见下文）。

## 三、判定规则（三条硬规则）

### 规则 1：数字抽取必须先剔除噪声

旧实现 `\d+(?:\.\d+)?` 直接扫全文，把引用标识符当数字：

| 输入 | 旧实现抽出 | v2 抽出 |
|---|---|---|
| `` 见 api-v1-dt-registry 与 v2 权威库 `` | `['1', '2']` | `[]` |
| `最近一次训练是 2026-06-30` | 日期与数字混杂 | `[]`（日期单独剔除） |
| `27 个实体` | `['27']` | `['27']` |

v2 的顺序是：先剔反引号内容 / URL / 路径 / 含连字符或下划线的标识符 / 日期，
再要求数字前后不紧邻 ASCII 字母数字。

**这一条直接改变了历史结论**：SFT v6 被判「3/5 语义拒答但幻觉率仍 1.0」，
其中唯一的假数字来源正是 `api-v1-dt-registry` 的 `1`——一个合法引用被计成了编造。

### 规则 2：锚点用正则，裸数字自动加边界

旧实现 `any(a in ans for a in anchors)` 是子串匹配，`anchors=["B"]` 会被 `Bel` 命中，
**Tinian 那道题实际恒真**，锚点基线虚高 0.125。

v2 一律 `re.search`，并对纯数字锚点自动加边界（`(?<![\d.])9(?![\d.])`），
避免 `9` 命中 `79.1`。

### 规则 3：题面回显双向剔除

题面自带的数字（如「打掉 30%」里的 30）不参与判定——既不记命中也不记编造。
否则模型正确地重述题设就会被判编造。

## 四、显著性判定

13 道探针（8 事实 + 5 陷阱）的时代必须结束：单题 = 锚点 12.5pp / 陷阱 20pp。

**历史结论的强度重估**：

| 对比 | 旧报值 | 实际差值 |
|---|---|---|
| v6b 0.50 vs v7 0.375 | "剂量-反应明确" | **4/8 vs 3/8，差一题** |
| v6b 0.50 vs 基线 0.25 | "翻倍" | 4/8 vs 2/8，差两题 |

方向可能为真，但在 8 题样本上不足以称「明确」。v2 扩到 42 事实 + 48 陷阱后：

- 单题权重降到 2.4pp（事实）/ 2.1pp（陷阱）
- 所有比率附 **Wilson 95% 置信区间**（小样本下比正态近似可靠）
- **两模型区间重叠即判「无显著差异」**，不得宣称提升

Wilson 区间示例（陷阱题 n=48）：

| 干净题数 | 点估计 | 95% 区间 |
|---|---|---|
| 24 | 0.500 | [0.366, 0.634] |
| 36 | 0.750 | [0.612, 0.851] |
| 48 | 1.000 | [0.926, 1.000] |

注意 24/48 与 30/48 的区间大幅重叠——**这类差异应判为不显著**。

## 五、探针集纪律

1. **冻结版本**：`gate_probes_v2.json` 带 `version` 字段，改动必须升版本，
   并在报告中**并列新旧结果**，禁止原地覆盖历史分数。
2. **零碰撞断言**：探针与训练语料必须零重合（训练集=测试集的直接防线）。
   检查由 `check_disjoint()` 实现，`train_pipeline.sh gate` 会自动带上。
3. **七族覆盖**：基地属性 / 虚构场景 / 范围外时点 / 范围外编号 / 假设单位 /
   诱导估算 / **近似产物≠本问答案**。第七族是针对 SFT v6 残余失败新增的——
   模型检索到「近似真实」的产物就敢答（v2 库确有红方实体计数、
   pmtec_dqn_v2_training 确有训练时间戳），现有六族没有覆盖这个更细的区分。

## 六、自检

指标实现本身必须可验证：

```bash
python pmtec_system/scripts/eval_citation_gate.py --selftest
```

11 项断言覆盖：干净拒答记满分、标识符不计数、题面回显剔除、`Bel` 不命中 `B 级`、
`9` 不命中 `79.1`、日期不计数、Wilson 区间跨中值，以及**主指标必须能区分
「干净拒答+编造」与「全编造」而旧口径不能**。

`train_pipeline.sh selftest` 会调用同一套自检，纳入交付前的机器检查。

---

## 七、历史分数如何对照

旧门禁（13 探针）与新门禁（90 探针）**不可直接比较数值**。要对照历史模型：

1. 用新门禁重跑该模型 → 得到四项指标；
2. 在报告中同时列出旧值并注明「旧口径为 token 加权、拒答零权重」；
3. 不要做「新值 vs 旧值」的百分比提升叙述——分母、探针集、判定规则全都变了。

正确做法见 `docs/PMTEC-参谋官SFT训练报告.md` 里程碑 7 的表格：同一模型两套口径并列，
说明差异来源，不做跨口径的「提升」宣称。
